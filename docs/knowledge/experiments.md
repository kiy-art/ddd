# 実験ログ（施策と結果）

PDCAの詳しい記録。数値と判定は`experiments.csv`（台帳、1施策1行）に書き、ここには背景と注意点を書く。新しいものを上に足す。**結果が悪かった施策も消さない。**

様式：
```
## [EXP-NNN / STEPxx] 施策名（実施日）
- P 計画（仮説）：何を変えると、どの数字がどう動くと考えたか。根拠となるデータ
- D 実行：実施した内容
- C 評価：測る指標・比べる期間・実施前の数値 → 実施後の数値（取得元）。判定：改善 / 悪化 / 差なし / 判定不能（データ不足）
  - 同じ期間の市場の動き（セール・新モデル・季節）：`market_ledger.csv`・`market.md`
- A 改善：継続 / 拡大 / 修正（次の仮説） / 撤回
- 学び：次の提案に使える一般化した学び（`learnings.md`にも転記）
```

## [EXP-003 / STEP69] 様子見の人向け値下がり通知、メーカー×カテゴリページ、2商品比較ページ（2026-10-03）
- 仮説：
  - 判定が「様子見」の来訪者は、今買わずに去る。値下がり通知を登録してもらえれば、後日メールで呼び戻してクリックにつなげられる。
  - 「メーカー＋カテゴリ」や「A B 比較」の検索に、専用ページで表示されるようになる。
- 実施内容：
  - 判定の直下に通知の登録欄を置いた。ただし、Resendの独自ドメイン認証が済むまで表示されない。
  - `/category/[category]/[brand]`、`/compare/[a]-vs-[b]`のページを作り、サイトマップに追加した。
- 測る指標と、比べる期間：
  - 通知の登録件数と、通知メールからのクリック。
  - 新しいページの検索表示回数・クリック数（Search Console）。
  - 比べる期間：実施前の4週と、実施後の4週。
- 測定：未測定（通知はResendの独自ドメイン認証の待ち）

## [EXP-002 / STEP68] 検索意図に合わせた商品ページのタイトル自動最適化（2026-10-02）
- 仮説：検索クエリの意図（買い時・スペック・価格）に合う言葉をタイトルに入れると、検索結果でのクリック率が上がる。
- 実施内容：`retitle_product`施策。クリック率の差があるページについて、実際のクエリから意図を判定し、タイトルを変える。7日後に効果を自動で判定し、悪化していれば元に戻す。
- 測る指標：施策ごとの検索クリック率の前後比較（施策ログに自動で記録される）。
- 測定：未測定（検索データがたまるのを待っている）

## [EXP-001 / STEP65] ショップへのクリックを増やすCRO改善（2026-09-30）
- 仮説：スマホで最初のショップボタンが約2.4画面下にあり、一覧のカードにもボタンが無いことが、クリックの少なさの原因。
- 実施内容：
  - 購入ボックスを価格の直下へ移した（1,978px → 882px）。
  - 画面下に固定の購入バーを付けた。
  - 一覧のカードに「楽天市場で見る」ボタンを付けた。
  - 押された場所別のクリック集計を始めた。
- 測る指標と、比べる期間：PVあたりのショップクリック率と、押された場所別のクリック数（`product_sticky_bar`・`product_card`）。比べる期間：実施前の2週と、実施後の2週。
- 測定：未測定（押された場所の集計は9/30開始）
