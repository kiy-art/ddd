## インフラ・運用
- Renderの無料プランは、15分使われないとサーバーが止まる。再開に最大1分ほどかかる。（`.github/workflows/update-prices.yml`のコメント、2026-09）
- 日次ジョブ（価格取得〜レポート）は、2026-09-30時点で15分を超えるようになった。そのため、裏で実行して進み具合を確認する方式に変えた。（STEP66、Daily price update #12の失敗）
- Render無料プランには、Web Shell（コンソール）が無い。本番DBの操作は管理API経由だけ。（STEP16）
- 2026-10-05：本番DBをBasic-256mbに有料化した（承認依頼 #002）。期限は無くなった。プラン変更でDBが止まっていたのは約1分で、その間、管理APIは500を返した。Renderで有料の変更をするには、先にお支払い方法の登録が必要（APIは「Payment information is required」を返す）。
- **Renderの無料Postgresは、作成から30日で期限が切れる**。期限後はアクセスできず、14日の猶予を過ぎると全データが削除される。`golf-deals-db`の期限は2026-10-20 17:06Z。（Render API `GET /v1/postgres`、2026-10-04。https://render.com/docs/free）→ 承認依頼 #002（2026-10-05に有料化して解決。無料プランで新しいDBを作るときは、引き続き注意）
- このリポジトリには、DB全体を書き出し・取り込みするAPIが無い。CSVで取り込めるのは商品と価格だけで、IDは引き継げない。DBの引っ越しは簡単ではない。（`backend/app/csv_import.py`、SEのレビュー、2026-10-04）
- 日次ジョブのcronは6:00 JSTだが、実際の実行時刻はずれる（例：10/4は03:08Z＝12:08 JST）。本番作業と重ならないようにするには、時刻をずらすだけでなく、直前に実行中でないことを確かめる。（監査、2026-10-04）
- 本番のバックエンド・フロントエンドは、どちらもブランチ`claude/golf-deals-mvp-w7yy2l`へのpushで自動デプロイされる。（Render API `GET /v1/services`、2026-10-04）
- 2026-10-04から、作業環境のAPI認証情報で、本番の管理APIとRender APIに接続できる（値はAIからは見えない）。
- 作業環境（Claude Codeのクラウド）からは、通信先として許可したドメインにしか接続できない。（2026-10-04、reference siteで接続を拒否されて確認）

## 収益化
- 楽天：アフィリエイトID設定済み（`RAKUTEN_AFFILIATE_ID`）。商品リンクは楽天のアフィリエイトURL。
- Amazon：トラッキングIDは`parjp-22`（2026-09-22発行）。PA-API（価格の取得）は、売上実績ができるまで使えないため、検索リンクのみ。
- Yahoo!ショッピング：バリューコマース経由。リンクの変換にはsidとpidの両方が必要（片方では成果が付かない）。2026-10-04時点で、Yahoo!ショッピングへの提携申請とsid・pidの共有は社長の作業待ち。（STEP67）
- 値下がり通知メール：Resendの共用テスト送信元（onboarding@resend.dev）は、アカウントの持ち主宛てにしか届かない。来訪者向けには、独自ドメインの認証が必要。（STEP69）

- 掲載商品の価格帯（本番の300商品、2026-10-04、経営企画部）：全体の中央値は40,700円、平均は54,909円。カテゴリ別の中央値は、アイアン127,600円、パター96,250円、ドライバー77,000円、距離計48,400円、ボール6,660円、グローブ2,040円。高い商品は、楽天の報酬の上限（1件1,000円）にかかる。
- 報酬率（要再確認。公式ページを直接は開けず、検索結果で確認）：楽天はジャンルによって2〜4%で、1商品あたり上限1,000円。Amazonは2024-08に紹介料の上限が廃止された。スポーツ用品の料率は3%か4%で、未確認。
- ASPの確定報酬は、発生した月より遅れて出るのが一般的（推測・要確認）。撤退などの判断には発生報酬を使い、確定値は後から照らし合わせる。（経理、2026-10-04）

## 表示・法令
- 「最安」「必ず」などの言い切りは、景品表示法のリスクがあるため使わない。価格の取得は1日1回なので「リアルタイム」とは書かない。Amazonは価格を取得していないので「Amazon最安値」とは書かない。（STEP68）
- サイトにプライバシーポリシーのページが無い（2026-10-04時点）。値下がり通知でメールアドレスを預かるため、整備が必要。
