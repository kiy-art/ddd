## 議題1：目標の進み具合と集客の打ち手の絞り込み
- 推す案：条件付き。週次の打ち手は「①10/24前に公開する物の確定 → ②計測の土台 → ③トップ刷新」の順に絞り、1部署1本までにする。クリック率の基準値は「ショップクリック ÷ GA4の商品ページPV」を、10/17以降の連続7日で取り直す。
- 理由：
  - 現状はクリック25/60（42%）で、期待ペース54.8%を下回り、直近7日6・前7日8で減速（議題の事実、管理API 2026-10-17）。60に届くには残り14日で35、1日2.5が要る。直近7日は約0.86/日で、約2.8倍が必要（計算：35÷14、6÷7。部内検討の集計）。
  - 集客直結の型（SEO・コンテンツ・SNS・CRO）の提案は30件中5件、採用2件のみ。提案の過半は運用・組織・提携側（22/30）（proposals.csv）。打ち手が分散していたので、絞る意味がある。
  - 基準値が取れない原因は計測不能（EXP-010の基準は「未取得（管理API 401）」、EXP-001・003も実施前が未取得、experiments.csv）。GA4が1日分では分母にならないため、基準値は「取れた日から7日」を暫定とし、前後比較は書かない（推測：1週間では季節・セールの交絡が大きい）。
  - 5部署が遅れ（経理・総務・マーケ・営業・Webデザイン）、型は外部待ち・計測不能・優先順位・担当の穴（部内検討）。材料不足ではなく詰まりの解消が先。

## 議題2：今夜できた成果物の反映可否
- 推す案：条件付き賛成。反映の順番は、①総務の指摘のうち法令に関わる修正（Amazon定型文、「AIが毎日データを分析」の言い過ぎ、「(最安)」の範囲と時点）→ ②SEのcanonical → ③ZXiガイドとX投稿 → ④トップ刷新（build・スマホ幅の検証が済んでから）。トップの大きな変更は判断ボード扱いの方針に従う。
- 理由：
  - 成果物はそれぞれ検証が未完（canonicalは未build、トップ刷新はbuild・スマホ幅が未検証、ZXiの日程は公式未確認。議題の事実）。検証が済んでいない物を同時に出すと、効果が混ざって判定できなくなる（EXP-001が楽天マラソンとD1〜D3の同時デプロイで交絡した前例、experiments.csv）。

## 議題3：サイトの土台(比較ページの絞り込みと停止対策の費用)
- 推す案：サイトマップ除外は賛成（レベルA、元に戻せる）。有料化は、その前にRenderの停止理由の確認を先に頼む（社長に出す前に原因を確定）。
- 理由：
  - 比較ページ629件はサイトマップ1,143件の55%（議題の事実。629÷1,143）。以前から比較ページの比率が高いと指摘されていた（learnings.md：840件の54%が2商品比較、74%が整形されていない商品名）。除外は戻せるので、先に動いても損が小さい。
  - ただし、除外の効果は測らないと分からない。PRP-20261005-mk-1は「絞り込みはEXP-003の後」と条件が付いており、EXP-003（新ページの表示・クリック）は未測定のまま。除外の前に、比較ページの表示回数とクリックを取り（SCで）、「効いていないから外す」と言える状態にする。
  - 有料化の判断材料が不足している。503の原因は未確定で、無料枠切れは推測（議題）。台帳上は、Web2つが無料で月750時間をワークスペース全体で共有する（contracts.csv。要確認と書かれている）。これが原因なら、2つで約1,488時間（24×31×2）が必要になり、枠を超える計算になる（推測）。一方で、原因が別（デプロイ失敗など）なら、有料化しても止まる。確認に費用はかからない。
  - 有料化は月約$7（約1,100円、推測）で、必要売上は月約14,400円→約15,500円（経理の試算、推測）。DBの有料化（INV-001）も、12月に発生報酬が月300円未満またはクリックが月60未満なら見直す条件が付いている（investments.csv）。固定費を積む前に、その条件の進み具合を見る必要がある。
- 見込み効果：控えめ。サイトマップ除外は検索の評価を集中させる狙いだが、効果は未測定で、推測。有料化は止まるリスクを下げる守りで、報酬を増やす根拠は台帳に無い。
- 費用・リスク：除外は0円。誤ると比較ページ経由の流入を失う（流入量は未取得）。有料化は月約1,100円（推測）の追加で、固定費として残る。期限は11/1（無料枠のリセット）。
- 決裁レベル：サイトマップ除外A、有料化B（費用が出る提案は必ずB）。原因確認は0円なのでA。
- 過去の試行：INV-001（DB有料化、2026-10-05実施。効果は未測定、見直し日は2026-11-02・12-07・2027-01-11）。EXP-003（比較ページ追加、未測定）。
- 市場・時期：11/1の無料枠リセットが期限。感謝祭と楽天マラソン第3弾（10/24）のあいだに止まると、機会損失が大きい（推測）。
- 測り方：原因確認は10/20までに結果を台帳へ。除外後はSCの表示回数・クリックとインデックス数を2週後に見る。503の発生回数と時刻を記録し、有料化後の停止ゼロを判定の基準にする。
