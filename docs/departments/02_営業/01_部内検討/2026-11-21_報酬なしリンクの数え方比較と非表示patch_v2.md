## 3. patch v2(2026-11-21_メーカー商品ページ行の非表示_v2.patch)
11/20版との違いと理由:
- 旧版は「楽天ドメインかつ affiliate_url に rakuten.co.jp を含む」で隠した。v2は **affiliate_url の pc= が product_url と完全一致のときだけ** 隠す。別の商品ページを指す楽天URLを誤って消さない(今は451/451一致なので件数は同じ)。
- example.comのダミー(D4)も同様に隠す。本物のメーカーURL(C35)は残す。
- ラベル修正: コードの実際の表示は「メーカー公式サイト」(shopRows.ts 186行)で、11/20資料の「メーカー商品ページ」は誤記。楽天に飛ぶ行に「メーカー公式サイト」と書くのは誤認のおそれがあり、隠すことで解消。
- 確認: `git apply --check` 成功(リポジトリのルートで、2026-11-21夜、現在のmainに対して)。ビルド・テストは未実行(全体統括が適用時に実行)。
- 適用後の確認(全体統括へ): (1)Bの商品ページで「公式サイトを見る」行が出ない、Cの商品では出る (2)product/[slug]/page.tsx 193行の officialShop が null でも壊れない(コード上は null 許容。今夜は未ビルド) (3)計測 cta_type=official のクリックが以後0になること。
