## 2. 再計測の手順(誰でも同じ数字になるように固定)
1. 取得元: 公開の `GET {backend}/api/products?limit=1000`(掲載中のみ・認証不要。backendのURLは render.yaml/インフラ記録のとおり)。審査待ちも数えたいときは管理API `/api/admin/products`(社長または全体統括のトークン。営業は持たない)。
2. 取得日時を記録する(掲載数が日々動くため。11/18 0:03時点の掲載商品KPIは449で、取得件数と一致するか確認)。
3. 上の定義で区分に振り分け、区分別・カテゴリ別の件数を出す。ホスト名だけを見る。リンク先は開かない(絶対ルール5)。
4. 公開分と審査待ち分を分けて書く(同じ母集団でないと開始値と比べられない)。
5. 結果は「取得元・取得日・母集団(公開のみ/審査待ち込み)」を付けて台帳に1行。
