## 1. 社長にお願いする操作(所要5〜10分の目安=推測)
画面写真・アカウントID・料率や特別条件の数字は送らない。返答は「はい/いいえ/空欄(分からない)」だけで足りる。メニュー名はVCの画面の変更で違う場合がある(推測)。見つからなければ「分からない」でよい。

1. VC(バリューコマース)の管理画面にログインする。
2. 「提携中」「提携申請中」などの広告主一覧(メニュー名は「プログラム管理」など、推測)を開く。
3. 一覧の検索欄に「Yahoo!ショッピング」と入れて検索する。
4. 結果のYahoo!ショッピングの状態を見る。「提携中」なら Q1=はい。承認待ち・否認・未申請なら、そのどれかを返す。
5. 「未申請」だった場合だけ、申請ボタンを押してよいかを決める(Q2)。押すなら申請し、「申請した」と返す(申請は社長作業)。
6. 検索欄に「ゴルフ5」と入れて検索する。提携できる案件が出るか(あり/なし)を見る。
7. 検索欄に「アルペン」と入れて検索する。同じく あり/なし を見る(アルペンはコード上すでに提携扱い。承認#004・10/30記載。管理画面と一致するかの確認)。
8. (任意)Yahoo!ショッピングの案件ページに、期間限定の増額表示(例:ブラックフライデー)が出ているかを はい/いいえ で返す。数字は返さない。
9. 上の返答を判断ボードの返信欄に1行で書く。

## 2. 返答の様式(コピーして使える)
```
Q1 Yahoo!ショッピング(VC)の提携状態: 提携中 / 承認待ち / 否認 / 未申請 / 分からない
Q2 未申請なら申請してよい: はい / いいえ / 申請済み / 該当なし
Q3 ゴルフ5の案件: あり / なし / 分からない
Q3 アルペンの案件: あり / なし / 分からない
Q4(任意) 期間限定の増額表示: あり / なし
```
返答期限案:11/30(Yahoo!BFは11/22〜11/29。BF中の確認は難しいので、期限を過ぎたら通常の週で可。回答が無ければYahoo!の報酬見込みは0として扱う=11/8案と同じ)。

## 4. 効果・デメリット・リスク(同じ重さで)
- 効果:目標の「VC承認」が確定し、同じ調べ物の繰り返し(営業の検索)が止まる。金額は、Yahoo!の直近クリックが数件で、提携が通っても月数十円規模(推測。knowledge.md 10/14・11/13行)。月1万円への寄与はほぼ0。
- 社長の作業が5〜10分増える。クリックが少ないため、得られる金額に対して作業が割に合わない可能性がある(推測)。
- 承認が出ても、新アフィリエイトの条件(24時間以内のカート投入+89日)がVC経路にも当たるかは未確認。条件の細部は管理画面の案件ページで見えるが、個別条件は公開リポジトリに書かない。
- 目標達成に見える点の注意:「提携完了」は状態の改善であり、報酬が実際に付くかは別。報酬が付いたかは、経理の月次(ASPごとの発生・確定の合計)で確認する。
- 申請が否認される可能性がある。否認でも、費用は0円で失うものは無い。
- 「報酬が付かないリンク」の数え方(データ上459/画面上35)の主従は別件で、判断ボードBに11/22提出済みの2案比較表(01_部内検討/2026-11-22_…)で決める。今夜の資料はその代わりにはならない。
