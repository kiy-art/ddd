## 議題1：集客(30日クリック18→30)に効く施策の適用可否
- 推す案：条件付き。Webデザイン所管の②固定バー比較入口patchは「適用してよいが、測定付き・撤退線付き」。優先度は①ガイド・③canonicalより低い（自部署の画面変更では18→30に届かない）。総務の「毎日記録・毎日更新→1日1回」修正は賛成（画面の文言なので、事実と合わない表記を残すより直す）
- 理由：直近7日のクリック4件は他店ボタン（cta_alt）3・主ボタン1で、固定バー経由は0（出典：事実.md placement、knowledge.md 11/5）。固定バーは購入ボックスが画面外にある時だけ出る導線で、「比較」への入口が無い（推測）。1か所だけ変える小さな変更で、タップ領域は44px（SKILL.md 2章）。PVが1日16前後なので、変更の効果は14日で約224PVにしかならず、判定はほぼ不能（出典：2026-11-07_固定バー比較入口_測定付き.md）
- 見込み効果：控えめ0／標準+1／強気+2クリック/30日（推測、PV約500/30日×率の差0.2〜0.4ポイントの仮定）。標準で1×6円＝6円−費用0＝約6円/月。実績18の約+5%（1.06倍）。月1万円（必要クリック約2,400〜2,600）には届かず、目標30の不足12のうち約1/12。目標値を置いただけの数字ではなく、PV×率差の仮定による推測
- 費用・リスク：費用0円。デメリット：(1)効果が小さく判定不能の公算大（PV16/日）、(2)tsc・375px未検証のまま入れると崩れるリスク、(3)固定バーに要素が増えて主ボタンのクリックを食う（共食い）、(4)内部リンクで比較表に移るだけでショップクリックが増える保証が無い、(5)iPhone(WebKit)の見え方は未確認（knowledge.md 10/19の前例）。適用前に tsc と375px（検証用モック）を通すことを条件とする

- 過去の試行：EXP-010（他店ボタンの動詞・時点・差額）は反映後の結果が未確認／EXP-015（スマホUI4件同時、効果分離不可）は判定不能もありうる（experiments.csv、knowledge.md 10/31）。固定バーの「最安」時点表記は適用済み（10/20〜）。UI変更で測れた実績は無し

## 議題2：数字の確定と「判定不能」の扱い
- 推す案：分母1の目標（Webデザイン0/1）は「基準値を出した日に1」と定義し直さず、PV欠けなし14日の成立日まで0のまま、を提案。欠測日は「未取得」と記録し平均補完の数字は推測欄にだけ書く。Webデザイン基準値のための日次jsonの欠測（10/30〜11/4）はSE確認事項として賛成
- 理由：クリック率は分母のPVが欠けると過大になる（8.2%→補完後5.1%の前例、knowledge.md 11/2）。EPCは成約が1件違うと約3倍動くため、クリック数が少ない間は率・EPCとも「判定不能」と書くのが正しい（出典：議題2の事実）
- 見込み効果：直接のクリック増はなし（0）。誤った判断（過大な率で施策を採否する）を避ける効果。金額換算は不能
- 費用・リスク：0円。デメリット：「判定不能」が続くと施策の採否が先送りされ、学習が遅れる。目標の数え方を変えると見かけの達成が増える懸念（目標変更はBで社長判断）
- 決裁レベル：A（記録方式）／B（目標の変更）
- 過去の試行：10/24会議でクリック率は「線にしない＝記録のみ」に決定済み（議事録 2026-10-24、knowledge.md 10/27）
- 市場・時期：11/10 Amazon判定、12/10保留上限は営業の領域のため意見なし
- 測り方：PV欠けなし14日が成立する日（最短11/18）に、分子・分母・欠測日数を併記して記録
