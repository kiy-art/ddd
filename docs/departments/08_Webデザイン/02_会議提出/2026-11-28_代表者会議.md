## 議題3：判定の区切り方(P-011判定不能、P-014・P-015とSS期間の重なり)
- 推す案：①**SS期間(12/4 20時〜12/11 1:59頃)の前後で区切って別々に数える。合計だけで判定しない**。②判定の最低件数を決める:「**押下が合計10件未満、またはPVが450未満の群は『判定不能』で終了し、戻す・続けるの判断をしない**」(11/10記録の「2倍検出に1群約454PV」を基準に、P-008の12/2ルールと同じ考え方)。③P-011のガイド内ボタンは**続ける+末尾だけ直す**:自部署の `GuideEndShops` に根拠文を足すpatch(今夜、`01_部内検討/2026-11-28_ガイド末尾の店ボタンに値下がりの根拠文.patch`)を採るかを決める。やめるのは、14日後に判定不能でも続ける費用が0円で、やめて得られるもの(ページの短縮)が小さいため推さない。
- 理由：P-011の押下0は、GA4のガイドPV約3.5/日(11/27=3・11/28=4、kpi 11/28〜29。2日分のみ)×基準率4.5%で、7日の期待約1.1件・0件の確率約33%(推測の計算)=偶然で説明できる。つまり「ボタンが効かない」とも「効く」とも言えず、件数不足が原因。1件の差で判定が変わる規模(議題の事実)では、期間を延ばすより、区切りの数を減らして毎回の判定をまとめるほうが誤判定が減る。
- 見込み効果：patchは控えめ。前提:ガイドPV 14日約49(推測)×4.5%=約2.2件のうち、末尾の寄与は読了率が未取得で不明→+0〜1件/14日。EPC仮値6円で月0〜12円相当、費用0。式 0〜2×6−0。実績(直近30日11件)に対し+0〜18%(推測)。月1万円との距離は0.1%未満=学習が目的。区切りの決め方そのものの収益効果は「根拠なし」。
- 費用・リスク：デメリット:①区切りを細かくすると、1群あたりの件数がさらに減り、ほとんどの判定が「判定不能」で終わる(それが目的だが、施策の戻す・続けるが決まらず放置される恐れ)。②patchはtsc・375pxが未検証(今夜はビルド禁止)。見出しを「値下がりを記録した商品を店で確かめる」と言い切る変更があり、総務の表記確認が望ましい(同じ根拠の商品だが、今後の値下がり・他店より安いことは示さない)。③SSと重なる期間にpatchを入れると、patchの効果とSSの効果が分けられない。入れるなら12/4 20時より前(12/3まで)か、12/11以降。
- 決裁レベル：A
- 過去の試行：EXP-014・EXP-008(小標本で判定不能)・P-008(12/2に10件未満なら終了、11/25会議)。いずれも「件数不足で判定不能」で、延長してもPVが増えず判定できなかった。今回の最低件数ルールはこれらと同じ型。
- 市場・時期：SS(12/4〜12/11)は需要・価格が動く週で、通常期の基準率(4.5%)がそのまま使えない。BF(11/19〜12/7)も続いている。
- 測り方：施策ごとに「適用日・SS前の期間・SS中の期間・SS後の期間」を別の行に書き、各行にPV・押下・率(Wilson区間)を並べる。10件未満・450PV未満は「判定不能」と書くだけにする。
