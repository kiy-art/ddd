## 議題1：各部署の目標の進み具合
- 推す案：自部署の報告。Webデザインは遅れ(基準値 0/1、確定は11/18が最短)。目標の変更は不要、11/18確定を維持。
- 理由：11/4〜11/14の11日は欠けなしでPV103(出典:kpi/2026-11-05〜11-15.json)。クリック5÷103=約4.9%(Wilson95%区間 2.1〜10.9%)、同一人物のまとめ押しを1人と数える基準では2÷103=約1.9%(0.5〜6.8%)。前回(10日)の4.0%・1.6〜9.9%から更新。**訂正**:11/13の記録の「11/6以降8日のPV59」は誤りで正しくは81(0÷81、上限約4.5%)。残り3日(11/15〜11/17)で14日分がそろう。
- 見込み効果：基準値の確定自体は収益を生まない(根拠なし)。役割は、後続のUI案の効果を測る物差し。分母が約100PVのため幅は広く、「基準」としては弱い(推測)。
- 費用・リスク：費用0円。リスク=①訪問者基準は自分で決めた定義(誤判定あり)。②GA4の後日の値の増加で分母が過小になりうる。③11/18の時点でPVが1日4〜10台のままだと、確定しても1か所の変更の効果は測れない(2倍の検出に約454PV/群=約45日分)。
- 決裁レベル：A
- 過去の試行：EXP-004・EXP-010(CRO、10月)はどちらも判定「未測定」。PV不足で効果判定できた施策は0件。
- 市場・時期：11/22〜はBFでPV・クリックが変わりうる。基準期間(11/4〜11/17)はセール前なので、セール期間は別に注記して混ぜない。
- 測り方：11/18に kpi/2026-11-05〜11-18.json の ga4.pageviews(snapshot_date基準)14日分と、同期間のクリック増分を、件数基準・訪問者基準の2本+95%区間で確定。場所別は4まとまり(A一覧/B商品ページ主導線/C店比較/D他)。

## 議題3：店別の価格とボタンを並べる表示を、価格の古さによる誤認を避けて出せるか
- 推す案：条件付き賛成。「店別価格の表示は既にある」ので新規実装は不要。patch `01_部内検討/2026-11-14_価格欄の古い価格表示と文字色.patch`(表示のみ・1ファイル3か所)を、**基準値確定後の11/18夜に適用**する。しきい値(3日)の短縮は今回は見送り。
- 理由(コードを読んだ事実。出典:lib/shopOffers.ts、lib/shopRows.ts、StoreComparisonTable.tsx、page.tsx 395〜545行)：
  - 取得3日超の価格は「最安」の比較に入らず、7日超は数字が出ない。時点は時刻まで表示。比較表は「N日前の価格(時点)・最新は販売ページで確認」と出る。誤認を避ける土台はできている。
  - 穴①:購入ボックスの他店ボタンでは、3〜7日前の古い価格が新しい価格と同じ大きさで出て、日数は切れうる小さい補足にしか無い(BF中は価格が日々動く)。②:価格カードの他店価格が/40、見出し/45で、白地のコントラスト4.5:1(AA)に未達(knowledge.md 10/11の計算)。時点の注記が読めないのは、時点を薄くしない方針に反する。
  - patch:古い価格を小さく(text-sm)し数字の真下に「N日前の価格」、文字色を/65に。PR表記・時点の内容・主ボタンの選び方・並び順・placement名は変えない。git apply --check合格。
  - 閾値短縮を見送る理由:Yahoo!は11/14に更新14件/スキップ785(API 429。出典:事実.md)。3日→1〜2日にすると、比較に入るYahoo!価格が大きく減り「店別比較」自体が成り立たなくなる恐れ(新しい価格の商品数は未取得)。
- 見込み効果：クリック増は根拠なし(PV4〜10/日では測れない)。主目的は誤認防止と可読性(景表法リスクの低減・守り)。EPC仮値6円(出典:11/1会議)なら、仮に月1クリック増えても6円。式「クリック×EPC−費用」で費用は0円。月1万円の利益との距離はほぼ変わらない。
- 費用・リスク(デメリットも同じ重さで)：①効果が測れない(判定不能)。②適用が基準期間(〜11/17)の途中なら基準値が汚れる→11/18以降に適用。③他店の新しい価格が濃くなり、主ボタンへの視線が分散する可能性(推測)。④3〜7日前の古い価格は見え続ける(小さくなるだけ)。⑤tsc・375px・ビルド未実施。⑥EXP-004・EXP-010の上に重ねるので単独の効果は分離できない。⑦購入ボックスの「現在の最安値」「◯◯が最安」は言い切りに読めうる(時点つき・比較した店の限定は既にあるが、総務の確認事項)。
- 決裁レベル：A(費用0円・元に戻せる)
- 過去の試行：EXP-004(古いYahoo!価格を主役にしない並び替え、10/5)=未測定、EXP-010(他店ボタンの動詞・時点・差額、10/11)=未測定。EXP-016(「最安値」をtitleから外す)=進行中で、表記の方向は同じ。
- 市場・時期：楽天BF 11/19 20時〜、Yahoo!BF 11/22〜(二次情報)。価格が日々動く時期に古い価格の見せ方を整えたい。価格.comのドライバー一覧は店別価格を出さない(1ページ確認のみ、全体の傾向とは言えない=推測)。PAR.の店別価格は差別化点なので維持する。英語記事の取消線・割引率は一般EC向けで根拠が弱く、PAR.の方針(「通常価格」「%オフ」不使用)で採らない。
- 測り方：クリックは `by_placement` の product_detail_cta・product_detail_cta_alt・store_comparison(・_top)の合計を、適用前14日(基準値)と適用後14日で比較。PVが足りなければ「判定不能」と書く。撤退線:適用後に3〜7日前価格の行のクリックが0件のまま2週続く場合や、苦情・誤認の指摘があれば元に戻す(全体統括が git revert)。
