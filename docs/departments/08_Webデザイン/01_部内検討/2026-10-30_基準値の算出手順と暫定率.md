# 2026-10-30 クリック率の基準値の算出手順(10/31用)と暫定率

選んだ理由: 10/23臨時の結論(画面改善は止め中)に従い、UIのpatchは作らない。基準値(10/31)を「誰がやっても同じ数字になる」手順に固定する(レベルA・費用0・コード変更なし)。

## 1. 事実(出典: docs/knowledge/kpi/2026-10-30.json=管理API 10/29 15:23Z、確認日 2026-10-30)

## 2. 暫定クリック率(積み上げ。起点=10/16時点の累計25)
- PVが取れた日(10/17〜10/29): 10/17=8、18=8、19=12、20=8、22=9、24=10、25=10、27=10、29=5 → 9日で80PV。
- 未取得の日: 10/21・10/23・10/26・10/28(4日)。
- 分子: 起点25→31で+6。10/26回に増えた3件は、10/26のPVが未取得なので分子から外す→3件。
- 暫定クリック率=3÷80=約3.75%。**判定不能**(分子3件。1件で約1.25ポイント動く)。
- 参考(全部入れた場合): 6件÷(80+10/26のPV不明)。分母が不明なので率は書かない。
- 注意: 10/29のPV5は前日までの8〜12より低い。1日窓の取得タイミング差の可能性(推測。10/24分は後日7→10に増えた前例あり)。

## 3. 10/31の算出手順(固定。上書きしない・この順)
1. 窓=10/17〜10/30の14日(同じ曜日を2回ずつ含む)。セール期間があれば別に注記。
2. 分母=窓内の各日のGA4 PVを、**その日の最新スナップ**で採用(10/24の例のように後日増えるため)。取れない日は「未取得」と列挙し、日数も併記。
3. 分子=窓内に増えたショップクリック(累計の差分)。分母が未取得の日のクリックは分子から外し、外した件数を併記。
4. 率=分子÷分母。分母のPVが14日分揃わない/分子が10件未満なら「判定不能」と書く(基準値としては暫定扱い)。
5. 場所別は2段で出す: ①placement名ごとの件数、②A〜Dのまとまり別(分類表は 2026-10-27_場所別集計の分類表と暫定率.md の3章)。placement別のPVは未取得なので、場所別の率は出さず件数と構成比のみ。
6. 窓の累計差分が管理APIの last_30d と食い違うときは、累計(total)の差分を正とし、食い違いを併記(窓の定義はSEに確認、推測)。

## 5. デメリット・リスク
- 取れた日が9/14日しかなく、基準値は上限寄り・下限寄りのどちらにも偏りうる(欠けた日のPVもクリックも不明)。
- 分子が3〜6件で、率の誤差は大きい。10/24会議の結論どおり、この率は線(合否の基準)にしない=記録のみ。
- 分子から外す扱いは率を恣意的に動かす可能性があるので、外した件数を必ず併記する。
