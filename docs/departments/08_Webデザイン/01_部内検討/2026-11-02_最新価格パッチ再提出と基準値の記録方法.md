## 基準値の算出と記録の方法(配置変更の前に必須)
目標「クリック率の基準値を出す(0/1件)」の材料。パッチ適用の前後比較は、この基準値を先に固定してから行う。
1. 分子: ショップクリック(管理API kpi-summary shop_clicks.total)。起点=10/16時点の25。
2. 分母: GA4 PV。kpi-summaryは1日窓なので、日次スナップshot(docs/knowledge/kpi/*.json の ga4.snapshot_date と pageviews)を日付ごとに積み上げ、同じ日付は最新スナップで上書き、取れない日は「未取得」。
3. 分子と分母は同じ日付範囲に揃える(未取得日のクリックは分子から外す、または率を「上限」と書く)。
4. 14日以上・同曜日を含める(スキル追加点検)。
5. 率は「まとまり別」(A一覧/B商品ページ主導線/C店比較/Dカード等。10/27分類表)と全体の2段で記録。placement別PVは未取得のため場所別の率は出せず件数のみ。
6. 記録先: 部内検討に1行ずつ(日付/PV/累計クリック)の表。適用日は別行で明記し、適用前の14日が基準値。

## 暫定の基準値(2026-11-02時点、出典: docs/knowledge/kpi/2026-10-17〜29.json、事実.md 11/1のPV6)
- 期間 10/17〜11/1(16日)。PVが取れた日は10日: 10/17=8、18=8、19=12、20=8、22=9、24=10、25=10、27=10、28=4、11/1=6 → 合計85PV。未取得: 10/21・23・26・29・30・31(6日)。
- 累計クリック 25(10/16)→32(11/1)=+7(16日分)。
- 計算(分子16日・分母10日)=7÷85=約8.2%は過大(上限)。未取得6日のPVを取れた日の平均8.5/日で補うと約136PV、7÷136=約5.1%(推測)。
- 結論: 暫定 約5〜8%、**判定不能**(分子7件、1件で約0.7〜1.2ポイント動く)。確定は、PV欠けのない連続14日が溜まってから(11/14ごろ以降、推測)。
- 注意: 10/24のPVは後日7→10に増えた例があり、直近日のPVは後で増える(率は下がりうる)。
- 直近30日のクリック23(7日5)はすべて楽天。直近7日の内訳 popular_rakuten_ranking 3・product_card 1・product_sticky_bar 1。
