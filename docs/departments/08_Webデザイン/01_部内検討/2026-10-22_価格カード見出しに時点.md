# 2026-10-22 価格カード見出しに時点を付ける + クリック率の暫定基準値

## 1. クリック率の暫定基準値(DQ-6)
- 分母: GA4の日次スナップショット(1日窓)の積み上げ。10/15=12、10/17=8、10/18=8、10/19=12、10/20=8、10/22=9(計57PV)。10/16・10/21の日は未取得。(根拠: docs/knowledge/kpi/2026-10-16〜10-23.json の ga4)
- 分子: ショップクリック累計が25(10/14〜10/22朝まで)→27(10/23記録)で+2。(根拠: 同json shop_clicks.total、10/14の累計25は knowledge 2026-10-14行)
- 暫定値: 2 ÷ 57 = 約3.5%。ただしPVの2日分が欠けるので実際はこれより低い(上限寄り)。**確定の基準値ではない**。サンプルが2件で判定は不能。
- 確定は10/31(PVが14日以上・同曜日を含む)。それまで日次PVの積み上げを続ける。依頼: GA4の日別PV(7日窓)をkpi-summaryに追加(欠け日をなくす)。
- 場所別(直近7日2件): 人気ランキング1、店舗比較1。7日前は7件だった(商品ページ主ボタン・他店ボタン等)=減少傾向。(根拠: kpi/2026-10-23.json)
