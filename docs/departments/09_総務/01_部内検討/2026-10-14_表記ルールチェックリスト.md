# 表記ルール チェックリスト(1枚版) 2026-10-14 総務部

文言(マーケ・Webデザイン・SE)を出す前に、上から全部「はい」になるか見る。総務は弁護士ではない。迷ったら「専門家への確認を推奨」と書いて止める。

## A. 「最安」「最安値」
- [ ] 何の中で最安か(範囲)を同じ画面に書いた。例:「PAR.が記録した楽天市場・Yahoo!ショッピングの中で」。Amazonを含めない(PAR.はAmazon価格を取得していない)
- [ ] いつ時点かを書いた。例:「10/14 06:33時点」。取得から3日超の価格は「最安」にしない(実装済みの基準 frontend/lib/shopOffers.ts)
- [ ] 「過去最安」は「PAR.の記録上」と書き、履歴が足りない商品には使わない
- [ ] 「必ず」「最も安い」「どこよりも」「保証」を使っていない
- [ ] ボタン単体の「(最安)」は、近くに範囲と時点の一文がある時だけ

## B. No.1・ランキング・「人気」
- [ ] 出典(誰の・いつの・何のランキングか)を書いた。例:「楽天市場の売れ筋ランキング 10/14時点」
- [ ] 出典が無い「No.1」「業界初」「大人気」は使わない

## C. 二重価格(「定価より」「%OFF」「通常価格」)
- [ ] 比べる元を文で明示した。次のどちらかだけ:
  1. メーカー希望小売価格(公表を確認できたものだけ。オープン価格の商品に「定価」と書かない)
  2. PAR.が記録した直近30日の中央値(平均と中央値を混ぜない。「30日平均より」と書くなら平均)
- [ ] 「◯%OFF」だけを単独で出さない(比較元が無いと不可)
- [ ] 将来価格・出品者の「通常価格」との比較を使っていない
- [ ] 予測価格は「予測。保証ではない」を同じ場所に書き、予測の幅が根拠なく大きくないか(下限が現在値の半分以下など)を数字で確認した

## D. PR・アフィリエイト表記
- [ ] ページ最上部(最初の画面)に1回。商品カード・比較表より前に置いた
- [ ] 比較表・ランキング・ショップボタンの見出しの近くにも「PR」または「広告を含みます」がある
- [ ] 文字の大きさが本文以上、色の薄さが本文と同等(現状 PrNotice は12px・65%で未達。別件)
- [ ] Amazonアソシエイトの定型文(「Amazonのアソシエイトとして、PAR.は適格販売により収入を得ています。」)を削っていない。Amazonが支援・後援しているように書かない
- [ ] X投稿は冒頭に #PR

## E. Amazonまわり
- [ ] Amazonの価格・割引率を書いていない(取得していない)
- [ ] 感謝祭の記事で、楽天・Yahoo!の値下がり商品の見出しに「Amazonの価格ではない」と明示した
- [ ] 日程・ポイント条件(エントリー、1万円以上、上限1万pt、期間限定、一部対象外)を省かない
- [ ] 終了後(10/20以降)は「終了しました」に直した

## F. 実態との一致
- [ ] リンクの仕組みを変えたら免責・FAQ・プライバシーも同時に直した(参加ASP: 楽天・Amazon・バリューコマース)
- [ ] 日付・時刻は日本時間で、時点を書いた
