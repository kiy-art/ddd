## 2. 照合(消費者庁の目安 vs PAR.の実装)
- 目安:過去価格を比較対象にするなら、**セール前8週間のうち半分超の期間・合計2週間以上** 実際にその価格で売られた価格(本文未読の目安)。
- PAR.の「30日平均」「30日中央値」は、期間が最長30日(約4週間)で、表示条件は「記録7日以上」(ProductCard THIN_DATA_DAYS=7、消耗品は5点・7日以上)。**8週間の窓でも「過半・2週間以上」でもない**。さらに、PAR.の記録は「その時点でPAR.が取得した価格」であって、特定ショップでの実売期間ではない(推測:複数ショップの最安が混ざる。backendの集計式は未確認)。
- よって #1 の「30日平均への取り消し線」と #2 の「30日中央値への取り消し線」は、「元はこの価格で売られていた」と読める線を、目安を満たさない根拠で引いている点が最大の弱さ。
- 定価(msrp)は別の類型。メーカー希望小売価格との比較は、実際にメーカーが設定・公表した価格であれば「過去の販売価格」とは別扱いになるのが一般的(推測:価格表示ガイドラインの類型。本文未読)。ただし、発売から長い型落ち品や、メーカーが価格改定・オープン価格化した品では「定価」が実態と離れ、読者の期待と食い違う(11/22 ZXi型落ちの学びと同じ根)。msrp は models.py 363-370行のとおり調査済みの値のみで、出典は「編集部調べ」止まり(メーカーのページURLは画面に出ていない)。

## 3. 線引き案(1つにしぼる)
1. **取り消し線は「定価(メーカー希望小売価格)」の1種類だけ**。基準名を線の隣に必ず書く(「定価（メーカー希望小売価格）」)。
2. **30日平均・30日中央値には取り消し線を引かない**。文で「PAR.の記録(◯日間)の平均より◯%安い」と書く(線で『元の値段』に見せない)。
3. 「半額以下」「◯%オフ」を画像・投稿に出すときは msrp 基準だけにし、本文に「定価=メーカー希望小売価格」を添える(#5)。
4. msrp が発売後1年超の型落ち等は「発売時の希望小売価格」と書く(推測:発売日 release_date が既にデータにあるので実装可能)。
5. 値下がり速報(#3)は取り消し線をやめるか、「◯/◯時点」を併記(下の確認事項)。
