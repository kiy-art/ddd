## 3. マーケ書き直し用チェックリスト(セールガイドの title / description / 本文の日程。今夜の書き直し用)

### A. 景品表示法
1. 🔴 次の語は使わない:「最安」「最安値保証」「必ず安い」「絶対」「No.1」「業界最大」。入れるなら根拠(何と比べたか・いつ・記録期間)を同じ文に書く。
2. 🔴 「値下がりした」は **楽天市場のPAR.の記録(期間つき)** の話だけ。Amazon・Yahoo!の値下がりと読める書き方にしない(guides.ts 63行のfeatured見出しと同じ「楽天市場の価格(PAR.の記録)」を残す)。
3. 🔴 「セールでいくら安くなる」「BFが一番お得」と、まだ記録で確認できていない将来の値引きを示唆しない(有利誤認)。「値下がりを約束するものではない」の一文は本文に残す。
4. 🟡 割引率・ポイント倍率(例:「最大23%」)は、title/descriptionには入れない。入れるなら条件・上限・出典・「報道ベース」を同じ文に入れる(検索結果では文が途中で切れる。条件が切れる位置に置かない)。
5. 🟡 「定価」「通常価格」と比べる表現は、出典のある定価だけ。無ければ入れない。
6. 🟡 「セール前に」:楽天BFは11/19 20:00に開始済み。タイトルは「セール前に」を使わず、「セール中も」「買う前に」「日程と価格の確かめ方」にする。Amazon(11/27〜)・Yahoo!(11/22〜)の「前」と区別する。
7. 🟡 「PAR.の記録している価格」「買い時スコア」は優良誤認を避けるため「楽天市場は1日1回の更新、セール中の表示価格と違う場合がある」の注記を本文に残す(今ある。削らない)。

### B. 日程の「公式」と「報道」の区別
8. 🔴 公式の原文(ニュースリリースやAbout Amazon Japan)を **開いていない日程を「公式発表」と断定しない**。現状は原文未確認(コメント50〜53行)。全体統括が原文を開いて確認日を記録できれば「公式発表」を維持。開けないなら「公式発表とされる」「公式の発表によると(要約で確認)」と弱める(11/19の記録の🟡と同じ)。
9. 🟡 日程の各文に「出典の名前・記事日(または発表日)・確認日」。今のYahoo!は記事日11/5・確認日11/15で良い形。確認日は **実際に確認した日だけ** を書く(今夜書き直すだけで「11/20確認」と書かない)。
10. 🟡 titleとdescriptionに日程を入れる場合:楽天(11/19 20:00〜11/25 1:59)とAmazon(先行11/27 0:00〜、本セール11/30 0:00〜12/7 23:59)は公式、Yahoo!(11/22 0:00〜11/30 1:59)は報道ベース。検索結果で後半が切れても誤解がないよう、**Yahoo!はtitle/descriptionに入れず本文だけ** にするのが安全(推測:descriptionの表示は約120字で切れる)。入れるなら「(報道)」を日付のすぐ隣に。
11. 🟡 時制:楽天は「開催中」、Yahoo!は「予定」。曜日と時刻まで書き、日付は過去・未来で食い違わせない(例:11/25を過ぎたら過去形。TODO 11/25)。
12. 🟡 更新日:書き直したら「更新日」をページに出す(`dateModified` を publishedAt のままにしない)。

### C. ステマ規制・PR表記
13. 🔴 ページ最初の段落の【PR】文と上部のPR表示は **削らない・位置を後ろに動かさない**(本文と同等以上の文字サイズ)。
