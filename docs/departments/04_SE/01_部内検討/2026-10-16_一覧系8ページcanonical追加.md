- 直近7日のエラー: error 7 / warning 239(目標「週1,000件以下」は達成圏)(根拠: 01_全体統括の2026-10-16_事実.md)

## 変更(可逆・費用0円・DB変更なし)
各 page.tsx の `metadata` に `alternates: { canonical: "/<パス>" }` を1行追加(popular/page.tsx と同じ書き方。metadataBase は layout.tsx で設定済みなので絶対URLに解決される)。
- frontend/app/{brands,compare,deals,faq,guides,ranking,contact,disclaimer}/page.tsx

## 測り方
