# 月次の損益（経理）

1か月1ファイル（`YYYY-MM.md`）。月初の最初の代表者会議（水曜または土曜の夜）で、前月分を確定させる。

- **収益**：ASPごとの発生報酬・確定報酬。出典は社長から共有された数字だけ（Notionの受信箱、種類＝数字）。共有が無い項目は「未取得」と書き、0にはしない。
- **費用**：契約中のサービス（`docs/knowledge/contracts.csv`）の請求額。
- **利益**：2段で出す（経理の案。範囲は社長が決める：C6）。
  - 事業の利益＝ASPの報酬 −（Render・ドメイン・本番API・Resend）
  - 参考：Claude Code・Notionなども含めた全体
- **月1万円との距離**：必要なクリック数・成約数と、今の数字の比較。
- 金額の詳細や名義は、公開リポジトリには書かない。必要ならNotionの経営ボードに置く。
- 税務の判断はしない（記録の整理だけ）。
