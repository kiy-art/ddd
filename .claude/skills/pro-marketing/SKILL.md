# マーケティング部の専門スキル

## 1. キーワードは「意図」で分けてから選ぶ
1. 候補を集める：Search Consoleのクエリ（表示が多いのにCTRが低い・順位8〜20位）＞自社の商品データ（メーカー×カテゴリ）＞競合の見出し（WebSearch）。
2. 検索意図で4つに分ける：**買う直前**（「〇〇 最安」「〇〇 価格」）／**比べる**（「A vs B」「おすすめ」）／**調べる**（「〇〇 選び方」）／**指名**（ブランド名だけ）。PAR.で報酬に近いのは買う直前と比べる。
3. 1つのキーワード群に1ページ。同じ意図のページを2つ作らない（共食い）。既存ページで足りるなら新規より改善を出す。
4. 優先度＝見込みクリック（表示回数×目標CTR）×報酬への近さ ÷ 工数。順位の数字は出典（Search Consoleの期間）を付ける。

## 2. ページを良くする順番（効きやすい順）
1. タイトルと説明文：意図の言葉を前に置く。価格比較であること・時点（「毎日更新」など事実だけ）を入れる。
2. 最初の画面で答える：価格・ショップ数・買い時の判定を、スクロール前に見せる。
3. 独自の情報：PAR.にしかない価格の推移・値下がり履歴を使う。他サイトの言い換えだけのページは作らない（Googleの「有用なコンテンツ」「大量生成コンテンツの不正使用」に当たる恐れ）。
4. 内部リンク：カテゴリ → メーカー → 商品 → 比較 の道をつなぐ。

## 3. AI検索（AI Overview・チャット型検索）対策
- 質問に1〜2文で答える段落を、見出しの直後に置く。数値・時点・出典を書く。
- 表（価格・仕様）は、HTMLの表にする。画像にしない。
- 構造化データ（Product・Offer・BreadcrumbList）は、ページに見えている内容と一致させる。

## 4. X投稿
- 1投稿1メッセージ。冒頭で「何がいくら下がったか」を言う。#PRは冒頭付近（末尾のハッシュタグ群に混ぜない）。
- 効果はutm_source=xのクリックで測る。投稿の型（値下がり速報／比較／買い時）ごとに当たり外れを記録する。

## 5. 意見書の質の基準
- 「どのページ（URL）を・どう変え・何が何%増える見込みか（控えめ・標準）」まで書く。
- 見込みの根拠：過去の施策（experiments.csv）か、Search Consoleの実数。どちらも無ければ「推測」と書く。

## 一次情報（使う前にWebFetchで開いて確認し、確認日を knowledge.md に残す。開けなければ検索で正しいページを探す）
- Google検索セントラル「SEOスターターガイド」「有用で信頼性の高い、ユーザー第一のコンテンツの作成」「スパムに関するポリシー」
- Google検索セントラル「構造化データ：商品（Product）」
- X（旧Twitter）の広告・ブランドコンテンツに関するポリシー

## 育てるループ
このスキルの基準が足りなかった・外れた・古かったときは、`knowledge.md`の「スキル改善メモ」に1行で書く（`- YYYY-MM-DD [001] 何が足りなかったか → 直し案(根拠: 出典)`）。毎週土曜の代表者会議で、人事部がまとめて改訂案を出す（`docs/departments/README.md`の「スキルの育成ループ」）。
