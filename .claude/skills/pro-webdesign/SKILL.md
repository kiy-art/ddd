# Webデザイン部の専門スキル

## 1. CROの進め方（仮説 → 小さく試す → 測る）
1. 数字から問題を選ぶ：押された場所別のクリック数（by_placement）とPVあたりクリック率。PVが多いのにクリック率が低いページが最優先。
2. 仮説は1文で：「〇〇なので押されない。△△に変えれば□□%上がる」。理由は、ユーザーが迷う点（何を・どこで・いくらで・今買うべきか）のどれかに当てはめる。
3. 1回に変えるのは1か所。変更前の数値と、比べる期間（最低1〜2週、同じ曜日を含む）を先に決める。PVが少ないうちは差が出にくいので「判定不能」もありうると書く。
4. 結果は良くても悪くてもexperiments.csvに残す。

## 2. 価格比較サイトで効きやすい型
- 最安のショップと価格を、商品名の近くに一番大きく。2番目以降は差額（+〇円）で見せる。
- ボタンの文言は行き先がわかる形（「楽天で見る」）。価格は時点を添える。
- スマホ：ボタンは親指で押せる大きさ（目安：高さ44px以上）、横スクロールの表を避ける、最初の画面に価格を入れる。
- 信頼の材料：更新日時、掲載ショップ数、値下がりの履歴グラフ。

## 3. デザインレビューの観点（他部署の提案・自部署の画面）
階層（一番大事なものが一番目立つか）／一貫性（同じ役割は同じ見た目か）／状態（読み込み中・0件・エラーの画面があるか）／文言（短く、次の行動がわかるか）。

## 4. アクセシビリティ（WCAG 2.2 AAの主な基準）
- 文字と背景のコントラスト：本文4.5:1以上、大きい文字3:1以上。PR表記もこの基準を満たす（薄すぎるとステマ規制上も不利）。
- 画像に代替テキスト、ボタンに名前、キーボードで操作できる、色だけで意味を伝えない。

## 5. 守ること
- 競合からは考え方（配置・余白・情報の順番）だけを取り入れる。画像・文章・独自の見た目は写さない。
- PR表記・アフィリエイトの定型文・価格の時点表示は、見た目の都合で消したり薄くしたりしない。
