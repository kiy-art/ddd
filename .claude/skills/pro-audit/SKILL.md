# 監査の専門スキル（表記審査を含む）

監査は「止める」だけでなく、**線の内側で一番売れる表記**を示す。違反を見えにくくする案は出さない（ASPの提携解除＝事業停止に直結するため）。

## 1. 判定は3段階
🟢 そのままOK（過剰に守っている所は「削ってよい」と言う）／🟡 条件付きOK（何を足せばよいか）／🔴 NG（代わりの言い回しを必ず付ける）。運営モデル6章の「合格／条件付き合格／差し戻し」と対応させる。

## 2. ステマ規制（景品表示法5条3号、2023年10月施行）
- 要件：①事業者の表示である ②一般消費者が広告と判別しにくい。内容の良し悪しは問わない。
- 明瞭な文言：「広告」「PR」「プロモーション」。記事の最初の画面に1回あればよい。リンクごとの表記は不要。
- NG：周りより小さい文字、薄い色、ハッシュタグの山に埋める、気づきにくい位置だけ、動画で一瞬。
- SNSは冒頭付近に「#PR」。

## 3. 誤認表示（価格比較サイトで一番事故が起きる所）
- 優良誤認（品質を実際より良く見せる）・有利誤認（価格や条件を実際よりお得に見せる）。故意でなくても措置命令の対象。2024年10月施行の改正で、悪質なものに直罰が新設された。
- 「最安」「No.1」：比較の範囲・時点・方法を明示し、表示と調査が対応していること。→ 代わりの形：「〇月〇日〇時時点、掲載〇ショップ中の最安」。
- 二重価格（「通常価格〇円→」「〇%OFF」）：比べる価格に販売の実績が必要。PAR.側で根拠を持てないものは出さない。→ 代わりの形：「ショップ間の価格差〇円」「前日比〇円安」（自社データの事実）。
- 性能の断定（「飛距離が伸びる」）は根拠が無ければNG。感想は「筆者の感想」とわかる形ならよい。

## 4. ASP・Amazon規約
- Amazonアソシエイト：アソシエイトである旨の定型文。PA-APIの価格は取得日時と「変わる場合がある」旨の表示。
- 各ASP：PR表記の義務、禁止事項（指名キーワードの扱い・価格表示の制限など）。違反は提携解除・報酬没収。

## 5. 監査の手順
1. 提案・ページから、広告リンク・価格表示・比較表現・最上級表現・数字の主張をすべて抜き出す。
2. 1つずつ判定（🟢🟡🔴）。数字は出典をたどって検算する。
3. 過剰な守り（長い免責文・全ボタンのPR表記）は「削減候補」として挙げる。
4. 規約・法令は最新版を開き、確認日と出典URLを書く。
5. 迷うものは「要専門家確認」（消費者庁の相談窓口・弁護士）。監査は弁護士ではない。
6. スキルの改訂案（育成ループ）では、法令・安全・秘密情報のルールを弱める変更が無いかを必ず確かめる。弱める変更は差し戻す。

## 育てるループ
このスキルの基準が足りなかった・外れた・古かったときは、`knowledge.md`の「スキル改善メモ」に1行で書く（`- YYYY-MM-DD [001] 何が足りなかったか → 直し案(根拠: 出典)`）。毎週土曜の代表者会議で、人事部がまとめて改訂案を出す（`docs/departments/README.md`の「スキルの育成ループ」）。
